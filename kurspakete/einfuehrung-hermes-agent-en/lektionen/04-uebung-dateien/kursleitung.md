- Hermes creates the file (often with a short note about which command it ran).

- For fast learners: Hermes doesn't know any prices – it **estimates**.

**Follow-up:** "How do you know the file really looks like that?" – goal: **check** the result **yourself**, don't
just believe Hermes.
