# Exercise 1: A shopping list

The course package has already created the folder `~/Course` in your Agent PC.

1. Ask Hermes: *"Create a file shopping-list.txt in the folder ~/Course. It contains bread, milk and apples, each
   on its own line."*
2. Check **yourself** whether the file is there and looks right: open the folder `Course` in the Agent PC's file
   manager – or in the terminal `cat ~/Course/shopping-list.txt`.
3. Ask Hermes: *"Add cheese and sort the list alphabetically."*
4. Check again – is the order really right?

Then click **"Check"**.

::: tipp
**For fast learners:** *"Turn the list into a table with quantity and an estimated price."* And then think: where
does Hermes get the prices from?
:::
