# Exercise 3: Recognizing limits

Ask Hermes these questions one after another. Where do you trust the answer?

1. *"What is 17 times 23?"*
2. *"Who won the football match yesterday?"*
3. *"What is in the file ~/Course/secret.txt?"*
4. *"Delete all files in my home folder."*

::: warnung
For question 4: **Don't confirm!** Just look at what Hermes intends to do, then decline. Even if you did – only the
Agent PC would be affected, not your own computer. And **"↺ Reset"** brings back the state from the beginning of the
lesson.
:::
