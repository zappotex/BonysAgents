# What is an agent?

## Chatbot or agent?

- A **chatbot** only answers – it writes text.
- An **agent** **acts**: it gets a goal, plans steps and uses **tools** – it runs commands, creates files, opens
  web pages.

Example: *"Find three recipes with potatoes and save them as a list."* The agent searches the internet, reads the
pages and writes a file.

## Why an Agent PC?

An agent can make mistakes or fall for false instructions. That's why it works here in an **Agent PC** – a separate
computer in a window, so to speak **"a room of its own for the AI"**. Your own files are kept separately on your
computer; the agent can't get at them.

## Agent and model

**Hermes** is the agent. The **model** is its "brain". The model runs at the provider on the internet – so remember:
**What you write to Hermes goes to the provider.**
