# Bonus: Reset and template

This lesson is **optional** – in a course if there's time left or on a second date, on your own at any time.

## 1. Reset

Click **"↺ Reset"** at the top of this guide. The Agent PC goes back to the state at the beginning of this lesson.
Everything changed since then is lost – Bony's Agents asks first.

## 2. Shut down and start

In the main window: **"Shut down"**, wait, then **"Start"**.

## 3. Save a template

1. **Shut down** the Agent PC (templates only work when it's off).
2. **"Save as template …"** → name, e.g. `hermes-ready` → **"Create template"**.
3. Personal things (Hermes sign-in, browser data, your own files) do **not** go into the template.

## 4. A second Agent PC from the template

**"+ New Agent PC"** → choose your template at the top under **"Base"** → **"Create and start"**. The new Agent PC
is ready in seconds.

Then click **"Check"**.

::: tipp
Did Hermes break something? Delete the Agent PC and recreate it from the template – your own computer was never in
danger.
:::
