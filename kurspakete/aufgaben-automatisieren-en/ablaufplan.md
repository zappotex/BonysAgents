# Profile

| | |
|---|---|
| **Level** | Advanced |
| **Duration** | 120 minutes with a 10-minute break |
| **Target group** | People who have already used Hermes |
| **Prerequisites** | Agent PC with Hermes set up; Basic knowledge from “Introduction to Hermes Agent” |

All exercises work in `~/Course`; start scripts create the sample files so every lesson can be repeated with
“Reset”.

# Learning goals

1. describe tasks so that result and format are clear
2. have Hermes create research with sources and check the sources
3. have documents summarized and check the summary against the original
4. have files sorted and renamed – with a dry run before the real run
5. have recurring tasks run on a schedule

# Outline

## Lesson 1 – Writing good tasks (20 minutes)

**Goal:** Phrase tasks with goal, format and limits.

- Goal – format – limits – check
- Before/after examples
- Exercise: improve three tasks

## Lesson 2 – Research with sources (25 minutes)

**Goal:** A piece of research as a file with sources.

- Research in ~/Course/research.md with a list of sources
- Open two sources yourself and compare
- Check task (planned): file exists and contains “https://”

## Lesson 3 – Summarizing (20 minutes)

**Goal:** A summary that matches the original.

- The sample text is in ~/Course/texts in the starting state
- Summary in five points
- Cross-check: what's missing?

## Lesson 4 – Organizing files (25 minutes)

**Goal:** A messy folder gets sorted – first as a dry run.

- Starting state: folder ~/Course/mess with sample files
- First “show me what you would do”, then run it
- Reset if it went wrong

## Lesson 5 – Recurring tasks (20 minutes)

**Goal:** A task runs at a fixed time.

- Set up scheduled tasks in Hermes (according to the docs)
- Keep the costs and limits of free models in mind
- Wrap-up and outlook
