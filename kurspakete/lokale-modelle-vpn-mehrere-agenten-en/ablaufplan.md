# Profile

| | |
|---|---|
| **Level** | Expert |
| **Duration** | 180 minutes with a 15-minute break |
| **Target group** | People with experience in networking and the terminal |
| **Prerequisites** | Computer with at least 16 GB RAM (better 32 GB) or a graphics card for local models; Two Agent PCs with Hermes; Bony's VPN (optional) |

Local models need a lot of memory. Clarify before the course which participants' computers are suitable;
anyone without a suitable computer uses a free cloud model and works with a partner in lesson 2.

# Learning goals

1. name the pros and cons of local models
2. enter a local model with an OpenAI-compatible interface in Hermes
3. make Agent PCs reachable via the VPN or the Bony Network
4. let two agents with separate roles work on one task
5. assess privacy and resources with local models

# Outline

## Lesson 1 – Local or cloud? (25 minutes)

**Goal:** Know when a local model fits.

- Privacy, costs, speed, quality
- Hardware requirements (RAM, graphics card)
- Minimum context of 64K for Hermes

## Lesson 2 – Connecting a local model (45 minutes)

**Goal:** Hermes answers with a local model.

- Set up a local model server on your own computer (official source)
- Enter it in Hermes as your own server (hermes model)
- Check task (planned): provider entered in config.yaml

## Lesson 3 – Connecting Agent PCs (35 minutes)

**Goal:** Two Agent PCs reach each other.

- Turn on Bony's VPN or the Bony Network
- Check reachability
- What is visible in the network – and what isn't?

## Lesson 4 – Several agents (45 minutes)

**Goal:** Two agents complete a task together.

- Assign roles: research and writing
- Handover via a shared file
- Check the result

## Lesson 5 – Wrap-up (15 minutes)

**Goal:** Record your experiences.

- What worked better locally, what worse?
- Free up resources again
- Outlook
