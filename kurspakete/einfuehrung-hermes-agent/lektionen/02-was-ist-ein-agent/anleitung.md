# Was ist ein Agent?

## Chatbot oder Agent?

- Ein **Chatbot** antwortet nur – er schreibt Text.
- Ein **Agent** **handelt**: Er bekommt ein Ziel, plant Schritte und nutzt **Werkzeuge** – er führt Befehle aus,
  legt Dateien an, öffnet Webseiten.

Beispiel: *„Suche drei Rezepte mit Kartoffeln und speichere sie als Liste.“* Der Agent sucht im Internet, liest die
Seiten und schreibt eine Datei.

## Warum ein Agent-PC?

Ein Agent kann Fehler machen oder auf falsche Anweisungen hereinfallen. Deshalb arbeitet er hier in einem
**Agent-PC** – einem eigenen Rechner im Fenster, sozusagen **„ein eigenes Zimmer für die KI“**. Deine eigenen Dateien
liegen getrennt auf deinem Rechner; da kommt der Agent nicht heran.

## Agent und Modell

**Hermes** ist der Agent. Das **Modell** ist sein „Gehirn“. Das Modell läuft beim Anbieter im Internet – darum gilt:
**Was du Hermes schreibst, geht an den Anbieter.**

## Zum Zuschauen

Im Kurs zeigt die Kursleitung, wie Hermes eine Datei anlegt:

```
Lege im Ordner ~/Kurs eine Datei begruessung.txt an. Schreib hinein: Willkommen im Kurs!
```

Danach liegt die Datei wirklich im Dateimanager des Agent-PCs.
