# Die Liste „Agenten-Apps“

Auf dem Schreibtisch deines Agent-PCs liegt **„Agenten-Apps“**. Doppelklick – die Liste öffnet sich im Browser.
Sie funktioniert auch ohne Internet.

## Ein Eintrag lesen

Such den Eintrag **PdfCraft** und schau dir an:

| Angabe | Was sie dir sagt |
|---|---|
| **Stabil / Beta / Alpha** (oben rechts) | wie ausgereift das Programm ist. Alpha heißt: noch jung – für Experimente gut, wichtige Dateien vorher kopieren. |
| **Getestet** (oben rechts) | wann der Eintrag zuletzt in einem frischen Agent-PC ausprobiert wurde |
| **Dein Agent kann damit** | welche Werkzeuge der MCP-Server anbietet |
| **Lizenz** | ob das Programm frei ist (PdfCraft: MIT oder Apache-2.0) |
| **Prüfsumme** | ein Fingerabdruck der Datei. Stimmt er, ist die Datei unterwegs nicht verändert worden. |
| **Installieren & mit Hermes verbinden** | klappt auf: die **offizielle Quelle** des Herstellers und die Befehle zum Kopieren |

## Wichtig

- Bony's Agents installiert diese Programme **nicht** von selbst. **Du** entscheidest.
- Dateien für die Agenten gehören in den Ordner `~/Agent-Dateien`.
- Die neueste Fassung der Liste steht immer online – der Link steht oben in der Liste.

Zum Schluss: das **Quiz**.
