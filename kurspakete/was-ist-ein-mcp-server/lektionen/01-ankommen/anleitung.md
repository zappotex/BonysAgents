# Ankommen

Willkommen! In diesem Kurs bekommt dein Hermes **Werkzeuge**: Am Ende kann er PDFs bearbeiten – mit einem Programm,
das du selbst aus der offiziellen Quelle installiert hast.

## So läuft der Kurs

1. Ein Kopf ohne Hände – was ist ein MCP-Server?
2. Die Liste „Agenten-Apps“ auf deinem Schreibtisch
3. PdfCraft einrichten
4. Übung: Hermes arbeitet mit PDFs
5. Abschluss

## Bevor es losgeht

1. Starte deinen Agent-PC (Hauptfenster → Agent-PC wählen → **„Starten“**).
2. Doppelklicke auf **Hermes Agent** und gib `hermes --tui` ein. Schreib **Hallo!** – antwortet Hermes?
3. Noch nie eingerichtet? Gib `hermes setup` ein, wähle **Nous** und ein **kostenloses (free) Modell** und melde
   dich mit deinem **eigenen** Konto an.

Fertig? Klick auf **„Prüfen“**.

::: hinweis
Wer festhängt: **🆘 Hilfe anfordern**. Im Agent-PC darf man Fehler machen – dein eigener Rechner bleibt unberührt.
:::
