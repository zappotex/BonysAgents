# Übung: Hermes arbeitet mit PDFs

In `~/Agent-Dateien/pdf` liegen frische Beispiel-PDFs: `rechnung-maerz.pdf`, `rechnung-april.pdf` und
`protokoll.pdf`. Sag Hermes dazu, dass er **PdfCraft** benutzen soll – sonst sucht er sich vielleicht einen Umweg.

## 1. Zusammenfassen

*„Benutze PdfCraft: Fasse protokoll.pdf zusammen. Was wurde beschlossen?“*

Prüfe **selbst**: Öffne `protokoll.pdf` im Dateimanager (Ordner `Agent-Dateien` → `pdf`, Doppelklick). Stimmen die
drei Beschlüsse?

## 2. Eine Seite drehen

*„Benutze PdfCraft: Seite 2 von protokoll.pdf steht quer. Dreh sie gerade und speichere das Ergebnis als
protokoll-gerade.pdf.“*

Öffne `protokoll-gerade.pdf` – steht Seite 2 jetzt richtig?

## 3. Zusammenfügen

*„Benutze PdfCraft: Füge rechnung-maerz.pdf und rechnung-april.pdf zu rechnungen-gesamt.pdf zusammen.“*

Öffne `rechnungen-gesamt.pdf` – zwei Seiten, März zuerst?

Dann klick auf **„Prüfen“**.

::: tipp
**Für Schnelle:** *„Wie hoch sind beide Rechnungen zusammen?“* – und rechne selbst nach.
:::

::: warnung
PdfCraft ist noch **alpha**. Mit eigenen, wichtigen PDFs immer an einer **Kopie** arbeiten.
:::
