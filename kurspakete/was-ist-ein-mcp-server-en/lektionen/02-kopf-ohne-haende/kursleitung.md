**Live demo** in your Agent PC (without PdfCraft): the same request as in the guide. Depending on the model, Hermes
tries `pdftotext`, Python or suggests installing something. The detours are exactly what's instructive: "It knows
what would need to be done – but it has no suitable tool."

- Picture: "a clever head without hands". MCP = the socket you plug tools into.
- Important for later: an MCP server only gets **one folder** (`--root`). That way the agent can't edit anything
  outside it.
- The start script puts `invoice-march.pdf`, `invoice-april.pdf` and `minutes.pdf` (page 2 sideways) into
  `~/Agent-Files/pdf`. Prepare the same files in your presentation Agent PC beforehand (work through the course
  package yourself or copy the files).
