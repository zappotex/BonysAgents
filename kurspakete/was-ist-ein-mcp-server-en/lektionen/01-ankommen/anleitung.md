# Getting started

Welcome! In this course your Hermes gets **tools**: by the end it can edit PDFs – with a program you installed
yourself from the official source.

## How the course works

1. A head without hands – what is an MCP server?
2. The "Agent Apps" list on your desktop
3. Setting up PdfCraft
4. Exercise: Hermes works with PDFs
5. Wrap-up

## Before we start

1. Start your Agent PC (main window → choose the Agent PC → **"Start"**).
2. Double-click **Hermes Agent** and type `hermes --tui`. Write **Hello!** – does Hermes answer?
3. Never set it up? Type `hermes setup`, choose **Nous** and a **free model** and sign in with your **own** account.

Done? Click **"Check"**.

::: hinweis
If you're stuck: **🆘 Request help**. In the Agent PC you're allowed to make mistakes – your own computer stays
untouched.
:::
