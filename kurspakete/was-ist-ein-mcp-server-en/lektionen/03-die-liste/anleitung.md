# The "Agent Apps" list

On your Agent PC's desktop there's **"Agent Apps"**. Double-click it – the list opens in the browser. It also works
without internet.

## Reading an entry

Find the entry **PdfCraft** and look at:

| Detail | What it tells you |
|---|---|
| **Stable / beta / alpha** (top right) | how mature the program is. Alpha means: still young – good for experiments, copy important files first. |
| **Tested** (top right) | when the entry was last tried out in a fresh Agent PC |
| **What your agent can do with it** | which tools the MCP server offers |
| **License** | whether the program is free (PdfCraft: MIT or Apache-2.0) |
| **Checksum** | a fingerprint of the file. If it matches, the file wasn't changed on the way. |
| **Install & connect to Hermes** | expands: the vendor's **official source** and the commands to copy |

## Important

- Bony's Agents does **not** install these programs by itself. **You** decide.
- Files for the agents belong in the folder `~/Agent-Files`.
- The latest version of the list is always online – the link is at the top of the list.
