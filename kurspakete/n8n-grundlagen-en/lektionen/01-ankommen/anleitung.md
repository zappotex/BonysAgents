# Getting started

Welcome! Today you build your first **workflow**: a process that runs by itself. By the end, n8n sends new items
from an RSS feed to your phone via **Telegram**.

## How the course works

1. What is a workflow?
2. Open n8n and create an account
3. Prepare Telegram: a bot of your own
4. The first workflow: RSS → Telegram
5. Exercise: your own variant
6. Saving and wrap-up

## Before we start

- Start your Agent PC (main window → choose the Agent PC → **"Start"**).
- Have **Telegram** ready on your phone (or computer).

::: hinweis
If you're stuck: **🆘 Request help**. In the Agent PC you're allowed to make mistakes – your own computer stays
untouched.
:::
