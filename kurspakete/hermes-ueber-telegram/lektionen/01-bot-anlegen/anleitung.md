# Einen Telegram-Bot anlegen

**Ziel:** Ein eigener Bot mit Token existiert.

::: hinweis
Diese Lektion ist noch ein **Entwurf** – nur die Gliederung.
:::

1. In Telegram @BotFather öffnen, /newbot, Name und Benutzername wählen
2. Das Token nur in den Agent-PC übertragen – nie in einen Chat, nie beim Bildschirmteilen
3. Warum ein eigener Bot je Teilnehmer?
